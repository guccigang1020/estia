# ESTIA

פלטפורמת ניהול אירוח — צימרים, וילות ובתי אירוח.

## מה זה

מוצר SaaS רב-לקוחותי, נבנה מאפס. הבסיס הרעיוני הוא מערכת עובדת ומוכחת
שרצה היום על עסק אמיתי אחד (DES OLIVIERS) — אבל **המערכת ההיא לא נוגעים בה.**
היא ממשיכה לרוץ בדיוק כפי שהיא, ומשמשת כאן כשרטוט בלבד.

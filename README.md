# ESTIA

פלטפורמת ניהול אירוח — צימרים, וילות ובתי אירוח.

## מצב נוכחי

המערכת עובדת היום על עסק אמיתי אחד (DES OLIVIERS), כשני קבצי HTML עצמאיים
המחוברים ישירות ל-Supabase. הקבצים המקוריים שמורים כאן כנקודת התחלה.

## תוכן התיקייה

| נתיב | מה זה |
|---|---|
| `_original/estia_live.html` | אפליקציית הניהול החיה (בעלים + עמוד אורח) |
| `_original/desoliviers_site.html` | האתר השיווקי |
| `docs/ESTIA_אפיון_עומק.docx` | האפיון המלא, גרסה 3.0 |
| `docs/ESTIA_אפיון_עומק.txt` | אותו אפיון כטקסט, לחיפוש נוח |

`_original/` הוא הגיבוי החי — לא נוגעים בו. הפיתוח החדש ייבנה לצידו.

## מפת דרכים

- **שלב 1** — פיצול קוד, תשלומים (סליקה + Bit), חשבוניות אוטומטיות
- **שלב 2** — רב-לקוחותיות (businesses / units / tenant_id + RLS)
- **שלב 3** — ערוצי הפצה, תמחור דינמי, AI

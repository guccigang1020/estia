## מה נחשב שחרור

**שחרור** = גרסה שהועלתה לסביבה שמשתמש אמיתי יכול להגיע אליה.

**לא שחרור:** commit · merge · הרצה מקומית · סביבת preview · שער ירוק ·
"הפיצ'ר מוכן".

> אם אף אחד מחוץ לצוות הפיתוח לא יכול להגיע לזה — זה לא שוחרר.

## מספור גרסאות

`MAJOR.MINOR.PATCH`

|           | מתי                                                    |
| --------- | ------------------------------------------------------ |
| **MAJOR** | שינוי שובר עבור לקוחות קיימים, או אבן דרך מוצרית גדולה |
| **MINOR** | יכולת חדשה שאינה שוברת                                 |
| **PATCH** | תיקון באג, אבטחה או ביצועים                            |

**`1.0.0` = הלקוח המשלם הראשון שאינו DES OLIVIERS עובד במערכת מקצה
לקצה.** לא לפני. עד אז — `0.x.y`.

```markdown

**סביבה:** production · https://...

### מה נוסף

- ...

### מה תוקן

- ...

### מיגרציות

| #   | מה                                            | הפיך? |
| --- | --------------------------------------------- | ----- |
| 001 | `users`, `organizations`, `memberships` + RLS | לא    |

### בדיקות

- 340 בדיקות יחידה · עוברות
- 52 בדיקות אינטגרציה · עוברות
- **מטריצת בידוד מול מסד: 96 בדיקות · עוברות**
- E2E: 8 מסלולים · עוברים

### מה עדיין לא עובד

- ... ← חובה. שחרור בלי הסעיף הזה אינו כן

### סיכונים שהוכנסו

- ...

### שינויים שוברים

- ... (או: אין)

### מסלול חזרה

- ... ← איך חוזרים אם משהו נשבר
```

**שני הסעיפים שאסור להשמיט:** _מה עדיין לא עובד_ ו*מסלול חזרה*.
הראשון כי שחרור בלי הודאה במגבלות יוצר ציפייה שתישבר. השני כי שחרור
שאין ממנו דרך חזרה אינו שחרור — הוא הימור.

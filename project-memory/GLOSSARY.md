# ESTIA · מילון המונחים

> **אוצר מילים קנוני.** מונח אחד לכל מושג, בכל מקום — קוד, מסד נתונים,
> ממשק, תיעוד ושיחה.
>
> זה לא קפדנות לשמה. כשמסמך אחד אומר `business`, טבלה אומרת `tenant`
> וממשק אומר "חברה", אף אחד כבר לא בטוח אם מדובר באותו דבר — ומישהו
> בסוף בונה טבלה שנייה לאותו מושג.

---

## כלל העל

## `organization` — ולא שום דבר אחר

**המונח הוא `organization`.** הוא מופיע ככה בקוד, בשם הטבלה, בעמודה
`organization_id`, בהרשאות (`organization.view`) ובממשק ("הארגון שלך").

**אסור להשתמש כמילים נרדפות:** `company` · `tenant` · `business` ·
`account` · `client` · `customer` · "עסק" · "חברה" · "לקוח".

חריג יחיד: המילה **"דייר"** (tenant) מותרת כמונח **מקצועי-אבטחתי** בהקשר
של בידוד — "בידוד דיירים", "בדיקה חוצת-דייר". היא מתארת תכונה של המערכת,
לא ישות בסכימה. **אין ולא יהיה `tenant_id`.**

> הערה היסטורית: אפיון 3.0 השתמש ב-`businesses` וב-`tenant_id`.
> אפיון 4.0 גובר. ראה [`DECISION_LEDGER.md`](DECISION_LEDGER.md) החלטה 3.

## 1. זהות והרשאות

| מונח              | מזהה                | מה זה בעברית פשוטה                                                                                                                                                                           |
| ----------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ארגון**         | `organization`      | הלקוח שמשלם ל-ESTIA. עסק אירוח אחד — צימר בודד או חברת ניהול עם 40 נכסים. **גבול הבידוד:** כל הנתונים של ארגון אחד סגורים מפני כל ארגון אחר                                                  |
| **משתמש**         | `user`              | אדם עם חשבון ב-ESTIA. זהות אחת, סיסמה אחת, MFA אחד — **גם אם הוא עובד בשלושה ארגונים**. משתמש **אינו** שייך לארגון                                                                           |
| **חברות**         | `membership`        | הקשר בין אדם לארגון, ומה שמחזיק את כל מה שספציפי לקשר הזה: סטטוס, תפקידים, טווח, נכס ברירת מחדל, שפה, העדפות התראה. **זו הישות שמחליפה את `user.organization_id`**                           |
| **סטטוס חברות**   | `membership_status` | `invited` · `pending` · `active` · `suspended` · `removed`. **הסרת עובד מעבירה ל-`removed` ואינה מוחקת היסטוריה** — מה שעשה נשאר בשמו                                                        |
| **תפקיד**         | `role`              | שם שמחזיק צרור הרשאות. 16 תפקידי מערכת + תפקידים מותאמים. **המנוע לא מבחין ביניהם** — תפקיד הוא רק שם על קבוצת grants                                                                        |
| **הרשאה**         | `permission`        | מחרוזת שמתארת יכולת אחת: `booking.update`, `site.publish`. 98 בקטלוג. יכולת חדשה במוצר נולדת כהרשאה כאן קודם                                                                                 |
| **הרשאת שדה**     | `field permission`  | הרשאה לעמודה רגישה בתוך רשומה שכבר מותר לראות: `booking.view_price`, `guest.view_contact`. 7 קיימות                                                                                          |
| **Grant**         | `Grant`             | **המונח המאחד** — הרשאה או הרשאת-שדה. זה מה שהמנוע מקבל: `can(actor, grant, resource)`                                                                                                       |
| **שחקן**          | `actor`             | המשתמש כפי שנפתר לבקשה אחת: מי הוא, באיזה ארגון הוא פועל עכשיו, אילו grants יש לו, מה הטווח, ומה החבילה מאפשרת. **אין בו שדה `role`** — התפקידים כבר שוטחו                                   |
| **טווח**          | `scope`             | **איפה** ההרשאה חלה. `all_organization` · `properties[]` · `units[]` · `team` · `own_records`. תפקיד אומר _מה_; טווח אומר _איפה_. שניהם נדרשים                                               |
| **סיבת סירוב**    | `DenialReason`      | למה נאמר לא: `membership_not_active` · `cross_organization` · `missing_permission` · `plan_does_not_include` · `out_of_scope`. **ההפרדה מאפשרת לממשק להציע שדרוג במקום לומר "אין לך הרשאה"** |
| **פעולה רגישה**   | `sensitive action`  | פעולה שהרשאה לבדה אינה מספיקה לה — דורשת אימות מחדש, נימוק או אישור. 10 קיימות                                                                                                               |
| **צוות פלטפורמה** | `platform staff`    | עובד ESTIA. עוקף טווח בתוך ארגון שהוא נכנס אליו, **ולעולם לא עוקף בידוד דיירים ולא עוקף Audit**                                                                                              |

## 4. חבילות ומנויים

| מונח            | מזהה           | מה זה בעברית פשוטה                                                                                             |
| --------------- | -------------- | -------------------------------------------------------------------------------------------------------------- |
| **חבילה**       | `plan`         | מוצר מהמחירון: Basic · Direct · Pro · Management. **מחירים הם נתונים שנערכים בממשק ניהול, לא קוד**             |
| **מנוי**        | `subscription` | הקשר בין ארגון לחבילה שלו. **מחזיק snapshot של המחיר שסוכם** — עריכת מחירון לא נוגעת בלקוחות קיימים            |
| **יכולת חבילה** | `entitlement`  | **האם** הארגון קיבל פיצ'ר: `website`, `team`, `owner_portal`. שאלה בינארית. נבדקת **בתוך** שער ההרשאות         |
| **מכסה**        | `quota`        | **כמה** מותר: נכסים, יחידות, משתמשים, אחסון. **מזהירה ולא חוסמת** בתפעול שוטף. חסימה שמורה לפעולות שאפשר לדחות |
| **מחיר נעול**   | grandfathered  | לקוח שמשלם פחות מהמחירון הנוכחי כי נכנס מוקדם. **תכונה של הסכימה, לא הבטחה שמישהו צריך לזכור**                 |

> **`entitlement` מול `quota` — ההבדל שקובע התנהגות:** יכולת היא דלת
> נעולה, ולכן הכפתור פשוט לא שם. מכסה היא קו שהלקוח חצה **בגלל שהוא גדל**,
> ולטרוק לו דלת בפרצוף זו התגובה הלא נכונה.

## 9. מונחים שאסור להשתמש בהם

| ❌ אל תכתוב                                               | ✅ כתוב                       |
| --------------------------------------------------------- | ----------------------------- |
| `tenant_id` · `business_id` · `company_id` · `account_id` | `organization_id`             |
| `user.organization_id`                                    | `membership`                  |
| "לקוח" כשהכוונה לארגון המשלם                              | "ארגון"                       |
| "לקוח" כשהכוונה למי שמתארח                                | "אורח" (`guest`)              |
| `role` בתוך `Actor`                                       | `grants`                      |
| `if (role === '...')`                                     | `can(actor, grant, resource)` |
| "נכס" כשהכוונה לדבר שמזמינים                              | "יחידה" (`unit`)              |
| מחיר ב-`float` או ב-`numeric`                             | `Agorot` — מספר שלם           |
| "קבלה" כשמדובר במסמך מס                                   | "חשבונית" (`invoice`)         |

   עד אז, המשפט "ארגון א׳ לא קורא ארגון ב׳" הוא תכנון, לא ראיה.
   ראה [`G-007`](OPEN_GAPS.md).
2. **`audit/events.ts` בכיסוי 0% ובלי נתיב כתיבה.** Audit שלא נכתב
   אינו קיים, ואי אפשר לתעד למפרע.
3. **מפתחות זרים חסרים** בין `memberships`/`audit_events` לבין
   `properties`/`teams` שטרם נוצרו. שלמות רפרנציאלית זמנית פתוחה —
   נסגר במיגרציה 0006.
4. **הקוד לא ב-git.** ימי עבודה בלי גיבוי ובלי היסטוריה.
5. **אין CI**, ולכן `npm run verify` תלוי בזיכרון של מי שדוחף.
6. **שני אפיונים קיימים רק כשחזור** — [`G-002`](OPEN_GAPS.md).
7. **הצלחה מוקדמת קוראת כהשלמה.** 365 בדיקות ירוקות ותשתית מרשימה
   הן עדיין **אפס מסכי מוצר**. אף אחד לא יכול להירשם.

## 10. מה הלאה

**בסדר הזה:**

1. **להריץ `supabase/tests/isolation.sql` מול המסד ולפרסם את התוצאה.**
   זו ההוכחה שכל השאר נשען עליה.
2. `npm run verify` מלא, ותיקון מה שנשבר.
3. **Commit** של כל מה שיושב בעץ העבודה, ואז GitHub פרטי + Vercel.
4. Workflow ב-CI שמריץ `verify`.
5. נתיב כתיבת ה-Audit, ובדיקות ל-`audit/events.ts`.
6. שכבת שירות שקוראת ל-`can()` בפועל — נכון להיום המנוע נבדק אך לא נקרא.
7. מסכי הרשמה, כניסה ו-onboarding של ארגון.
8. מיגרציה 0006: `properties` · `units` · `teams`, וסגירת המפתחות הזרים.

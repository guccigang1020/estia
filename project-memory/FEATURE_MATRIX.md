## 3. יכולות שקיימות במערכת החיה ונדרש לבנות מחדש

**הקשר קריטי:** כל אלה **עובדות היום** ב-`_reference/estia_live.html` על
עסק אמיתי. ההחלטה לבנות חדש (החלטה 1) פירושה שכל אחת מהן צריכה להיבנות
מאפס. הן אינן "פיצ'רים חדשים" — הן **חוב מוצרי מיום אחד**.

הטבלאות שהמערכת החיה מחזיקה בפועל (נבדק): `bookings`, `villa`,
`checklist`, `products`, `orders`, `reviews`, `expenses`, `gallery`.
